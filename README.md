# FGId Export HTML3D

Export an IngeTrazo model as a self-contained interactive HTML file with materials, tags, and selected scenes. The viewer works offline and can include the loaded FGId point cloud.

Open **Extensions → Open plugins folder**, extract the release ZIP, and copy the `FGId_HTML3D` folder into the plugins directory. Restart IngeTrazo and choose **Extensions → FGId Export HTML3D**.

Tested with IngeTrazo 0.5.10.1. The extension uses GPL-3.0-or-later. The included Three.js and OrbitControls files use MIT.
